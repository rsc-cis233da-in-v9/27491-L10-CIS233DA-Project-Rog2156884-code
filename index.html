Exploring new web development techniques, reflecting on my progress, and preparing for the next steps in my career.

My Reflections

Throughout Lesson 10, I gained a better understanding of how CSS preprocessors can make styling websites more organized and efficient. Before this lesson, I was familiar with writing regular CSS, but working with SASS and SCSS introduced me to several techniques that can improve the way I structure my code.

Three New Concepts I Learned

  1. SCSS Variables: I learned how to create variables for colors and fonts instead of repeatedly entering the same values throughout my stylesheet. This will be useful when building websites that need a consistent theme or when making changes to an entire design.
  2. SCSS Nesting and Modules: I learned how to organize related selectors inside one another and use the @use rule to access variables from a separate theme file. I can use these concepts to keep larger website projects organized and easier to maintain.
  3. Extending Shared Styles: I learned how to use @extend to share common styling properties between different elements. During the practice activities, I used this technique to style multiple message boxes while changing their individual border colors. This can help reduce repetitive code in future projects.
